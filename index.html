PartPay UPI: Split & Pay

Split the plan. Keep the payment yours.

A payment planning utility, not a payment processor.

PartPay divides a larger total into sequential parts up to ₹1,999 each. It copies the current amount and opens a compatible UPI app; the user chooses the recipient, enters the UPI PIN, and completes the actual transaction entirely outside PartPay.

  • Automatic amount splitting
  • Sequential locked payment parts
  • Installed UPI app launcher
  • Manual payment confirmation
  • Optional 12-digit UTR storage
  • Resume unfinished plans
No accountNo runtime permissionsNo analyticsNo adsWorks offline

PartPay cannot verify whether a transaction occurred. The user's UPI app or bank transaction history remains the authoritative record.

Less noise. More intent.

Each SS Pixels product can be different in purpose, but the product principles stay consistent.

  • Collect less by default.

    Use local storage where it makes sense and only request access when the feature actually needs it.

  • Make the main action obvious.

    A good mobile interface should explain itself before the user needs a tutorial.

  • Use platform-native strengths.

    Modern Android architecture, Jetpack Compose, Play services and system APIs where they improve the experience.

  • Price clearly. No traps.

    One-time purchases with clear prices, and free games kept free with ads rather than paywalls.
